# Wichita State Tomayko Collection — Voyager FDS materials

## What's in this folder

| File | Description |
|---|---|
| `MS_87-08_B37_FF41.pdf` | *Computer Command Subsystem, Flight Software Design Description, Vol. I, Rev. G.* JPL document 618-235, 22 January 1980. 205 pages. Distribution list includes Larry Zottarelli. |
| `MS_87-08_B37_FF42.pdf` | *MJS FDS Processor Architecture and Instruction Set.* JPL Interoffice Memo MJS:2.64A, J. Wooddell, 7 October 1974. The canonical FDS architecture specification. 10 pages. |
| `MS_87-08_B37_FF43.pdf` | *Mariner Jupiter/Saturn 1977 Flight Equipment Flight Data Subsystem Hardware.* JPL document MJS77-4-2006-1A, 20 March 1978. 46 pages. |

## Provenance

These are scans of paper documents held by the **James E. Tomayko
Collection of NASA Documents** (collection MS 87-08) at **Wichita
State University Libraries Special Collections**, Box 37,
Folder Folders 41–43.

The scans were originally produced by WSU on request and made
publicly available via the
[voyager-fds-emulator](https://github.com/Zaneham/voyager-fds-emulator)
GitHub repository. They are reproduced here as part of the broader
research archive.

## Use status

Per WSU's distribution to the public voyager-fds-emulator repository,
these materials are redistributable for research and educational use.
The originating documents are JPL contractor records authored by
NASA-funded employees in the 1970s.
